# 💻 XPERT IT SOLUTIONS Portal

A professional web-based management portal developed for **XPERT IT SOLUTIONS** to manage IT service inquiries, student registrations, and administrative operations through a centralized platform.

##  Overview

The **XPERT IT SOLUTIONS Portal** provides a professional online platform for managing client inquiries and student registrations. It also includes an administrative dashboard for managing records, monitoring activities, viewing analytics, and exporting data.

## ✨ Key Features

* **Client Management** – Manage and track IT service inquiries and project requests.
* **Student Registration** – Manage registrations for professional training programs.
* **Admin Dashboard** – Centralized dashboard for managing and monitoring records.
* **Data Management** – Search, filter, update, approve, reject, and delete records.
* **Analytics** – Visual representation of registration and inquiry data.
* **Data Export** – Export records for reporting and analysis.
* **Responsive Design** – Modern interface compatible with different screen sizes.
* **Professional Showcase** – Display services, courses, team information, and gallery content.

## Technology Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP
* **Database:** MySQL
* **Server:** Apache
* **Development Environment:** XAMPP
* **Libraries:** Chart.js, Font Awesome, GSAP


##  Installation Setup

1. Clone or download the repository.
2. Place the project folder inside the `htdocs` directory of XAMPP.
3. Create the required MySQL database using phpMyAdmin.
4. Configure the database connection according to your local environment.
5. Start **Apache** and **MySQL** from XAMPP.
6. Open the project in your browser using:

```text
http://localhost/project-folder/
```
